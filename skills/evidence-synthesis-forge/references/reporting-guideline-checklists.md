# Reporting-guideline & risk-of-bias checklist index

Adapted from Aperivue/medsci-skills `check-reporting` (MIT). Aperivue's own rule applies:
**marked-up item text that is an own-words summary is labelled as such, and instruments with
no open licence are summarised, never reproduced.** Consult the official instrument before
scoring a submission.

## How to use

Audit a manuscript item by item against the matching guideline/tool, marking each item
**PRESENT / PARTIAL / MISSING**. Pick the instrument by study design and review type.

## Selection map

- **Systematic reviews / meta-analyses** → PRISMA 2020; protocol PRISMA-P; scoping PRISMA-ScR;
  diagnostic accuracy PRISMA-DTA; abstracts PRISMA 2020 for Abstracts (own denominator);
  observational-pooling add MOOSE; synthesis-without-meta-analysis SWiM.
- **Randomised trials** → CONSORT (2025); +AI CONSORT-AI; protocols SPIRIT / SPIRIT-AI.
- **Observational studies** → STROBE; routinely-collected data RECORD; +MR STROBE-MR.
- **Diagnostic accuracy** → STARD / STARD-AI; QUADAS-2, QUADAS-3, QUADAS-C.
- **Prediction models** → TRIPOD / TRIPOD+AI / TRIPOD-LLM; PROBAST / PROBAST+AI.
- **Animal studies** → ARRIVE 2.0. **Case reports** → CARE.
- **Economic evaluations** → CHEERS 2022. **Surveys** → CROSS (+ CHERRIES).
- **Qualitative** → SRQR (all approaches); COREQ (interviews/focus groups).
- **Quality improvement** → SQUIRE 2.0. **Reliability/agreement** → GRRAS.
- **Radiomics** → CLEAR; **AI imaging** → CLAIM 2024, DECIDE-AI, MI-CLEAR-LLM.
- **Tumour markers** → REMARK; **target-trial emulation** → TARGET; **burden of disease** →
  GATHER.
- **Risk of bias / review quality** → RoB 2 (RCTs), ROBINS-I / ROBINS-E (non-randomised),
  ROBIS (reviews), ROB-ME (missing results), RoB NMA, NOS (observational),
  AMSTAR-2 (reviews), COSMIN (outcome measures).

## Licence tiers (do not violate when redistributing)

- **Permissive (CC BY 4.0 / CC0), verbatim OK with attribution:** STROBE, STARD,
  TRIPOD+AI, PRISMA 2020, PRISMA 2020 for Abstracts, CONSORT, SPIRIT, ARRIVE 2.0.
- **Non-commercial (CC BY-NC), summaries only, no commercial use:** ROBINS-I,
  MI-CLEAR-LLM, DECIDE-AI, SQUIRE 2.0.
- **No open licence found → own-words summaries only, never reproduction:** CARE, QUADAS-3,
  QUADAS-2, PROBAST, RoB 2, PRISMA-DTA, TRIPOD-LLM, CLAIM 2024, NOS.

**This index is a pointer, not the instrument.** Always open the official checklist (e.g.
prisma-statement.org) before scoring a real manuscript, and cite the guideline version used.

## Staleness pre-check

Before auditing, confirm the checklist version is current — guideline versions move (CONSORT
2025, SPIRIT 2025, TRIPOD+AI 2024, PRISMA-DTA 2018, etc.). An audit against a superseded
version is a defect, not a pass.
