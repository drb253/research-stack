# A short draft with deliberate citation defects

Neural retrieval improves recall on the benchmark (Smith, 2019). The effect held in a
second cohort (Smith 2019). A later replication extended it to clinical text
(Jones et al., 2021). The pipeline follows the standard two-stage design (Brown, 2018).

Chen puts it plainly: "memory is reconstructive, not reproductive" (Chen, 2020, p. 44).

The discussion repeats the main claim without a citation, which a careful author would
attribute (Smith, 2019).
